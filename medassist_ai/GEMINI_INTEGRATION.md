## 🎯 كيفية الاستخدام

### الخطوة 1: الحصول على API Key
1. افتح https://aistudio.google.com/app/apikey
2. اضغط "Get API key" أو "Create API key"
3. اختر مشروع أو أنشئ واحداً جديداً
4. انسخ المفتاح

### الخطوة 2: إدخال المفتاح في التطبيق
1. افتح التطبيق
2. اذهب إلى **البروفايل** > **إعدادات التطبيق**
3. الصق Gemini API Key
4. اضغط "💾 حفظ المفتاح"

### الخطوة 3: الاستخدام
1. افتح **دردشة مع AI**
2. اسأل أي سؤال طبي باللغة العربية
3. ستحصل على رد ذكي ومتطور من Gemini!

## ⚠️ معالجة الأخطاء

### الأخطاء المدعومة:

1. **API_KEY_INVALID**
   - رسالة واضحة بالخطأ
   - تعليمات للحصول على مفتاح جديد
   - رابط مباشر لـ Google AI Studio

2. **RATE_LIMIT_EXCEEDED**
   - إعلام المستخدم بتجاوز الحد
   - Fallback تلقائي لـ mock responses
   - شرح حدود الاستخدام المجاني

3. **SAFETY VIOLATIONS**
   - رسالة مهذبة عن سياسة الأمان
   - اقتراح إعادة صياغة السؤال

4. **NETWORK ERRORS**
   - رسالة خطأ واضحة
   - إمكانية المحاولة مرة أخرى

## 📝 مثال على المحادثة

### مع Gemini API:

**المستخدم:** ما أعراض نزلة البرد؟

**Gemini:** نزلة البرد (Common Cold) هي عدوى فيروسية تصيب الجهاز التنفسي العلوي. الأعراض الشائعة تشمل:

🤧 **الأعراض الأساسية:**
• احتقان الأنف وسيلانه
• العطس المتكرر  
• التهاب الحلق
• السعال الخفيف
• الصداع الخفيف
• آلام خفيفة في الجسم

🌡️ **الحمى:** نادرة أو خفيفة جداً (على عكس الإنفلونزا)

⏰ **المدة:** عادة 7-10 أيام

💊 **العلاج:**
- الراحة الكافية
- شرب السوائل بكثرة
- الغرغرة بالماء والملح
- استخدام مسكنات الألم عند الحاجة

⚕️ **متى تستشير الطبيب:**
- إذا استمرت الأعراض أكثر من 10 أيام
- إذا ارتفعت الحرارة فوق 39°C
- إذا ظهرت أعراض شديدة

📌 تذكير مهم: هذه معلومات عامة. يُرجى استشارة الطبيب المختص للتشخيص الدقيق.
