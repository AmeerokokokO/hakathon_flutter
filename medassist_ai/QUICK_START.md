# MedAssist AI - Quick Start Guide  

## 🚀 تشغيل التطبيق السريع

### الخطوة 1: تثبيت المكتبات
```bash
cd d:\Android_Studio\gavite\hakathon_flutter\medassist_ai
flutter pub get
```

### ال خطوة 2: تشغيل التطبيق
```bash
flutter run
```

أو لبناء APK:
```bash
flutter build apk
```

## ⚠️ ملاحظات هامة

### إذا واجهت أخطاء في الـ imports:
قم بتشغيل الأمر التالي لإصلاح المشاكل تلقائياً:
```bash
dart fix --apply
```

### لإصلاح الأخطاء الصغيرة:
```bash
flutter clean
flutter pub get
```

## 📱 اختبار المميزات

بعد تشغيل ال تطبيق:
1. ✅ الشاشة الرئيسية - 4 بطاقات تفاعلية
2. ✅ الدردشة مع AI - اضغط "دردشة مع AI"  
3. ✅ تحليل الأعراض - اضغط "تحليل الأعراض"
4. ✅ قائمة الأمراض - اضغط "الأمراض"
5. ✅ الوضع الداكن - زر toggle في الأعل ى

## 🔧 إعداد API (اختياري)

1. افتح **البروفايل** > **إعدادات التطبيق**
2. أدخل API Endpoint وال مفتاح
3. احفظ الإعدادات

## ✨ المميزات الجاهزة

- 8 شاشات كاملة مع animations
- 10 أمراض + 15 عرض طبي
- نصائح صحية يومية
- Dark/Light modes
- واجهة عربية كاملة
